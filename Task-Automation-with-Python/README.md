# Task Automation with Python

This project automates the process of organizing JPG files.

## Key Features

- Automatically checks the source folder for JPG files.
- Moves files to the `organized_images` folder.
- Displays the number of files moved.
- Shows the task status after execution.
- Displays the names of saved files when requested.
- Automatically creates the destination folder if it doesn't exist.

## Technologies & Concepts Used

Python | OS Module | Shutil Module | File Handling | Loops | Conditional Statements | User Input

## Project Description

This project demonstrates how Python can be used to automate repetitive tasks and make everyday file management more efficient.
